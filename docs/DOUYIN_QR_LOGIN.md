# 抖音扫码登录

抖音登录使用抖音网站自己的登录页面和二维码。网页上的“登录抖音”按钮会创建一个短期登录会话，服务端在隔离的 Playwright Chromium 上打开 `https://www.douyin.com/`，只把官方登录二维码转成图片返回给当前网页。手机抖音扫码并确认后，服务端保存登录态，后续抖音分享链接解析和下载会复用这份登录态。

这套功能是“网站登录态 + 扫码确认”，不是抖音开放平台 OAuth。它不申请开放平台应用、不返回开放平台 access token，也不会把浏览器 Cookie 或二维码票据放进接口响应、日志或前端状态。

## 使用流程

1. 通过私人站点认证打开下载器，在“抖音登录”区域点击“登录抖音”。
2. 用抖音 App 扫描页面显示的官方二维码，并在手机上确认。
3. 网页显示“已登录”后，再粘贴抖音分享文案或作品链接进行解析和下载。
4. 不再需要时点击“退出抖音登录”。退出会撤销本地托管登录态、清理解析缓存和临时 Cookie 文件；关闭二维码弹窗只停止轮询，不会退出已经保存的登录态。

一个服务实例同时只允许一个扫码会话。二维码会话最多持续 120 秒，过期后使用“刷新二维码”重新开始。登录态的本地保存上限为七天，并且不会延长抖音网站 Cookie 自身的有效期；平台提前失效时仍需重新扫码。退出、服务重启或登录态失效都不会伪造“已登录”状态。

官方安全验证由用户在运行浏览器窗口中手动完成。程序只识别“需要验证”的状态，不自动拖动滑块、读取验证码或绕过风控。桌面模式会打开独立的 Chromium 窗口；云端默认无头模式，遇到验证时必须由管理员在运行服务的设备上完成验证，不能保证云端环境始终能拿到二维码。没有拿到官方二维码、平台返回挑战或网络策略阻断时，界面会显示不可用/需要验证，而不是显示模拟二维码。

## 运行配置

`.env` 中可以设置：

```dotenv
# 绝对路径；不设置时依次查找 Playwright 自带浏览器和系统 Chromium 路径
NETPAN_CHROMIUM_PATH=
# 设为 false 完全关闭抖音扫码组件
NETPAN_DOUYIN_LOGIN_ENABLED=true
# 云端建议 true；桌面调试可设为 false 打开独立窗口
# NETPAN_DOUYIN_HEADLESS=true
```

应用生产依赖锁定为 `playwright-core@1.64.1`，但 `playwright-core` 不会自动替服务器安装浏览器。管理员应在服务器上安装一份与服务账户隔离的 Chromium，并让 `netpan` 账户只读执行。可以使用已审核的 npm 锁文件执行 Playwright 浏览器安装，例如在受控临时目录运行 `npx playwright install chromium`，再把实际浏览器目录移动到 root 拥有、服务账户可执行的 `/opt/netpandownload/browser`；或者配置 `NETPAN_CHROMIUM_PATH` 指向管理员安装的绝对路径。若使用 Playwright 浏览器缓存，设置 `PLAYWRIGHT_BROWSERS_PATH=/opt/netpandownload/browser` 后再执行安装。安装完成后应确认 `netpan` 能执行该二进制，但不能写入浏览器目录。

生产启动保持 Chromium 沙箱（`chromiumSandbox: true`）。不要给服务添加 `--no-sandbox`，不要复用管理员个人浏览器 profile，也不要为了浏览器而放宽 systemd 的 `NoNewPrivileges`、`ProtectHome`、`ProtectSystem` 或其他隔离项。现有 `netpan-web.service` 的 `MemoryMax=768M`、`TasksMax=128` 仍有效；安装浏览器后必须在目标服务器单独验收内存、进程数、用户命名空间和启动耗时，容量不够时应调整专属服务资源并审核，而不是绕过沙箱。

私人站点仍必须经过 Nginx HTTPS 和 Basic Auth。`/api/auth/douyin/*` 与其它 API 共享私人 Web token/origin 校验，二维码图片和状态接口均发送 `Cache-Control: no-store`。服务只监听回环地址，浏览器登录窗口不会变成公开代理。

## 登录态的保存与下载桥接

登录成功后，服务在 `NETPAN_DATA_DIR/auth/douyin/` 保存 AES-256-GCM 加密会话和单独的密钥文件，目录/文件使用仅服务账户可读写的权限。持久化数据只包含经过域名、路径、过期时间和 Cookie 名称校验的抖音 Cookie；公开状态接口只返回状态、时间和二维码 URL，不返回 Cookie 值。

抖音提取器优先使用这份托管登录态。为兼容 yt-dlp 的 Netscape Cookie 参数，调用子进程时会在同一私有数据目录中创建一个随机名称、`0600` 权限的短期明文 Cookie 文件，并在正常返回或抛错后的 `finally` 中删除。它只在提取器运行期间存在；进程被强制终止时不能承诺操作系统级的零残留，管理员应限制数据目录访问并在启动/维护时检查异常遗留文件。旧的 `DOUYIN_COOKIE_FILE` 仅在没有托管扫码登录记录时作为管理员配置的兼容回退；扫码退出或托管记录损坏/过期后不会偷偷回退到旧 Cookie。

公开页不含媒体时，已保存的扫码登录态也会用于读取官方作品页。该步骤只打开经过校验的数字作品 ID，读取官方详情响应或页面中的 JSON 数据；沿用媒体域名和作品匹配校验。浏览器按单作品、限时运行并在完成后关闭，退出登录后不会继续返回该会话取得的新解析结果。扫码窗口与作品读取都需要目标设备的 Chromium 沙箱和资源配置通过验收。
