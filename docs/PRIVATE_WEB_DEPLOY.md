# 私人网页版

完整初始化、独立账户、GitHub Actions 手动发布、服务与 Nginx 配置、健康检查及回滚，统一见 [腾讯云部署说明](TENCENT_DEPLOYMENT.md)。旧版 `/opt/netpandownload/app`、`3000/16800` 示例已被新的 `current` 发布结构、`3300/16801` 专用端口替代，不要混用。

在私人 HTTPS 网页粘贴链接并解析、选择文件、加入任务，实际下载完成后点击“保存到此设备”，文件通过流保存到当前手机或电脑。混合轮播和网页扫描仍可按类型及单项勾选。文件先下载到服务器，浏览器保存后不会自动删除服务器文件。

保留夸克、B站、YouTube、Instagram、HTTP 直链、静态扫描、批量任务及暂停/继续。YouTube 暂仅支持含音频的渐进式 MP4/WebM，不支持分离音视频合并。登录、CDN 过期、403 等实际限制不能用 Mock 成功替代。

Windows Electron 本地下载与交互式弹窗扫描继续保留；普通浏览器无法提供同等跨域交互能力。需要动态弹窗捕获时使用桌面端。

代码、CI 和 Mock 测试通过不代表腾讯云已部署或真实平台下载已验证；以对应发布运行和实测记录为准。
